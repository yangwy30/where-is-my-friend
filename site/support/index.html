Support

Help and feedback for the Where Is My Friend TestFlight beta.

Before reporting a problem

  • Confirm you are using the newest TestFlight build.
  • For city updates, check Location Services and the app’s sharing settings.
  • For notifications, check both the app’s notification page and iOS Settings.
  • Background refresh timing is controlled by iOS and is not continuous or instant.

Send feedback

Use TestFlight’s Send Beta Feedback action, or open a GitHub issue. Do not include authentication tokens, precise locations, or other sensitive information in a public issue.

Delete your account

In the app, open You → Delete account and confirm. If that action fails, report it through TestFlight feedback so we can assist with the request.

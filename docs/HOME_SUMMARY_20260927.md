# 首页相聚摘要与重复请求合并

## 范围与发布状态

这是上一轮好友计划分页后的进一步优化。源码和本地验证在本次提交中；**没有部署生产，也没有上传新的 TestFlight 构建**。前一轮生产发布确认仍未完成；审核中的 App Store 构建保持不变。航班供应商、订阅和查询额度未更改。

## 行为

- Friends 首页概览只返回最早 3 条相聚记录，同时保留准确总数。现有 Together soon 卡片位置和折叠交互保持不变；打开卡片才读取完整列表。
- 通知链接按相聚 ID 独立读取，不能因该记录不在首页 3 条预览中而判定失效。前台通知横幅也使用这条读取路径。
- 完整列表读取中显示局部加载状态；网络失败可以重试。详情读取失败和计划已失效分别显示，不增加全局同步提示。
- 版本未变化时保留已展开的完整列表；计划或授权变化时丢弃旧数据。退出账号、换账号、好友权限变化和保存计划均使未完成的旧读取失效。
- 同时发起的首页刷新合并为一次；自动启动/前台/首页刷新复用同账号 15 秒内的成功结果。手动下拉刷新仍强制读取。失败与离线结果不计入成功缓存；好友资料成功但计划失败时，后续会单独重试计划。
- 完整列表及同一条详情的并发请求分别合并。相聚详情的短期缓存仅在内存中，账号/授权/数据版本改变即失效。

## 接口与兼容

- 新迁移：`20260927030000_home_overlap_summary.sql`，依赖尚未上线的 `20260927020000_plan_pagination_and_bootstrap.sql`。
- `GET /v2/travel-plans` 增加 `overlapCount`、`overlapVersion`、`includesAllOverlaps`；概览中的 `overlaps` 最多 3 条。
- `GET /v2/travel-overlaps` 返回全部当前授权相聚记录；`GET /v2/travel-overlaps/:id` 返回当前用户有权查看的指定记录。
- v1 完整列表与保存接口保持兼容，旧 App 不会收到被截断的列表。
- 新 RPC 只允许 service_role 调用，API 使用认证得到的用户 ID；双方分享、好友关系、屏蔽和到期过滤继续由原 `travel_overlaps` 视图执行。

摘要减少 JSON 构造和传输量，但仍需计算相聚匹配、总数和版本；不能将它描述为消除了全部数据库计算。

## 验证

- 后端完整测试：124 项通过。
- Release 配置的本地模拟器编译成功；这不等于发行签名、TestFlight 上传或正式上线。
- iOS 单元测试：184 项通过，包括预览与总数、完整列表保留、详情并发读取、前台通知、账号/权限/保存竞态、失败重试、自动刷新复用、手动刷新以及登录初始化。
- 模拟器界面通过：展开全部 5 条相聚记录；冷启动通知直接打开第 5 条；创建计划、选择好友、取消共享后详情消失；无效通知链接安全退出。
- 城市选择使用演示夹具，避开旧 UI 测试对首页推荐城市及外部城市搜索结果的依赖；不把它当作真实 MapKit 搜索验证。
- 本轮未执行整套耗时较长的 UI 测试；执行了受影响的上述流程。

## 压力复测

同一台 Mac、本地真实 PostgreSQL、20 个业务连接；1,000 个合成账号，每人 100 个好友、10 份计划、100 万条分享授权。身份验证和 APNs 使用测试替身，公网、真实 Supabase Auth/Edge/PostgREST、推送网络不在测试范围内。

下表比较相同的 1,000 人突发浏览场景：每人 Friends、概览、好友计划第一页、Trips，共 4,000 个请求。

| 指标 | 上一轮分页后 | 本轮摘要优化后 |
| --- | ---: | ---: |
| 非预期请求失败 | 0 | 0 |
| 概览响应 p95 | 79,274 字节 | 32,487 字节（减少 59%） |
| 概览延迟 p95 | 3,625ms | 3,160ms |
| 好友计划第一页 p95 | 3,636ms | 3,201ms |
| 混合请求 p95 | 3,495ms | 3,106ms |
| 整个场景完成时间 | 6.17 秒 | 5.83 秒 |

这里的延迟是两次本机测量，不代表生产环境保证，也不把客户端去重虚算成服务器吞吐提升。高密度突发的概览仍约 3 秒，数据库匹配计算仍有优化空间。

另外验证了：

- 实际客户端首页路径 `POST /v1/auth/bootstrap` + 概览：1,000 人、2,000 请求，0 失败，混合 p95 2,839ms。
- 1,000 人分散在 60 秒刷新：2,000 请求，0 失败，p95 48ms。
- 100 人同时展开完整相聚列表：0 失败，p95 355ms。
- 首页预览 3 条、准确总数 200；展开返回全部 200 条，与旧版完整列表逐项一致；预览外的通知详情可单独取得。
- 好友计划走完 20 页，1,000 条无重复或遗漏。
- 同账号 400 次 SQL 并发初始化无冲突；32 次 HTTP 初始化全部成功。
- 同一计划版本 16 次竞争编辑：1 次成功、15 次明确冲突，符合预期。
- 模拟通知 1,000 条全部完成，无重复；早间生成分批 500 / 500 / 0，去重正确。

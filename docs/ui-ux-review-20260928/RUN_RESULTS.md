## 补充测试的失败与恢复

- 滚动后的系统标签栏收起：脚本先展开标签栏再选择目标，复测通过。
- 城市选择基线：脚本错误假定示例 Tokyo 必然在初始列表；实际有“已有旅行”时不显示示例列表。改从真实好友计划复制草稿，完成该草稿测试。城市搜索另有通过的用例。
- 系统确认弹层：小屏版本使用点弹层外部关闭，不一定提供单独 Cancel 按钮。按实际系统交互操作后，移除/屏蔽的取消流程通过。
- Widget 主题误标：主套件部分标签为 Light 的截图仍继承深色偏好。已在恢复浅色后补拍正确浅深色组件对照；不能按文件名推断实际主题。

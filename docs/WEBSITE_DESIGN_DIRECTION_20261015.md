# acrossus.app 网站设计方向（2026-10-15）

参考对象：cash.app、ramp.com。数值是在 1440×900 视口下，从两站的计算样式里实测得到的。

## 它们为什么好看

### Cash App

| 项目 | 实测 |
|---|---|
| 字体 | 只用一款自家字体 Cash Sans，标题、正文、按钮全是它 |
| 字重 | 标题全部 400（常规），不用粗体 |
| 标题 | H1 56px，行高 0.95，字距 -3%；H2 40px，行高 1.1，字距 -3% |
| 颜色 | 首屏整屏铺满招牌绿 `#00E013`，其余区块只有白和黑 |
| 按钮 | 胶囊形（圆角 999px），黑底或白底，字很小 |
| 首屏布局 | 左边大标题，中间一部巨大的真实 App 截图，右边一小段说明 |

### Ramp

| 项目 | 实测 |
|---|---|
| 字体 | 只用一款 Lausanne |
| 字重 | 标题全部 400 |
| 标题 | H1 64px，行高 1.0；H2 40px；卡片标题 24px |
| 颜色 | 白底、近黑字（不是纯黑），面板用很浅的暖灰；只有一个强调色，酸黄 `≈#E4F222`，只用在主按钮上 |
| 按钮 | 小圆角 6px，内边距 12×16 |
| 布局 | 便当盒（bento）式卡片网格，细边框，背景有很淡的点阵纹理 |
| 标题技巧 | 半句黑、半句灰（"**Cards & Expenses** that handle themselves"），一行里就分出主次 |

### 两家共同的五条规则

1. **大字号、常规字重、收紧字距。** 高级感靠尺寸和间距，不靠加粗。
2. **全站一款字体。** 不混衬线体和无衬线体，不用斜体。
3. **只有一个招牌色，而且用得很省。** Cash App 用在整屏首屏，Ramp 只用在一个按钮上，其余全是黑、白、灰。
4. **产品本身就是插图。** 直接放大尺寸、清晰的真实 App 界面，不画装饰插画。
5. **克制。** 每屏只讲一件事，标题不超过两行，眉标、小标签、要点列表都很少。

## 现在的网站差在哪

- **混了三种字型**：Georgia 衬线斜体（*somewhere.*）、粗体无衬线、系统字体。读起来像杂志排版，不像科技产品。
- **颜色太多**：navy、green、lime、paper、muted、line 六个色值，没有一个是招牌色。
- **奶油纸色背景**（`#f7f5ee`）显得旧、软，不够干净利落。
- **App 截图偏小**，摆在右侧小卡片里，存在感弱。
- **小元素太多**：眉标（"FOR FRIENDS IN DIFFERENT PLACES"、"01 / SHARED CITIES"）、编号列表、图注，画面显得碎。

## 给 Across Us 的方向

**一句话：Cash App 式的大胆首屏 + Ramp 式的精确网格。**

- **招牌色**：沿用 App 深色模式里的强调绿 `#A6E677`（`WIFTheme.fresh` 的深色值）。首屏整屏铺满，正好和 App 对得上。深色字用 App 的 ink `#13301F`。
- **字体**：全站只用一款免费的现代无衬线字体，推荐 **Geist**（SIL OFL 授权，可以自托管）。标题统一用 400，字距 -3%，H1 在桌面端 64–72px。中文回退到 PingFang SC。
- **其余颜色**：白 `#FFFFFF`、近黑 `#0E1A13`、浅灰面板 `#F4F5F1`、10% 透明度的细边框。没有别的颜色。
- **按钮**：主按钮用胶囊形黑底白字（"Download on the App Store"），次按钮用纯文字加箭头。
- **首屏**：绿底，左侧放 "See you somewhere."（不再用衬线斜体），中间放一部大尺寸 iPhone 显示 Friends 页，右侧一句话说明加下载按钮。
- **功能区**：白底，便当网格卡片，三到四张：同城提醒、旅行计划重叠、Trips、小组件。每张卡片的标题用半黑半灰写法，卡片里直接放真实截图。
- **城市徽章**：App 里已经有一整套城市徽章，可以做成一条横向滚动的"城市墙"，承担 Ramp logo 墙那样的角色。这是 Across Us 独有、别人抄不走的元素。
- **邀请落地页 `/i/用户名`**：同样绿底，大字写"Yang 邀请你加入 Across Us"，下面一个 App Store 按钮。分享出去的预览图（OG 图）也用同一套绿底大字。

## 不要做的

- 不用衬线斜体，不加粗标题，不用渐变，不用 emoji 当图标。
- 招牌绿不要同时出现在背景、按钮和文字三个地方，一屏只出现在一处。
- 不要堆眉标、编号和图注。

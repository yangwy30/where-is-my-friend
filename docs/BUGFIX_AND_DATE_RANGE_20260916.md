## 日期选择

- 编辑器只保留一行完整日期范围，点击后进入单个日历。
- 第一次点击选择开始日期，第二次点击选择结束日期，范围之间的日期连续高亮。
- 支持同一天、反向点选、跨月、跨年和闰日；取消不修改原日期。
- 未来计划保留目的地当地日期、最长日期跨度和最远开始日期约束。
- Trips 复用相同界面，保留原有可编辑过去行程的行为。
- 保存和“我也会去”继续使用原有权限确认；选择日期本身不改变共享范围。

## 稳定性修复

1. **旧离线操作覆盖新选择：** 在线写入和后台重试共用串行入口；新的共享设置先淘汰旧队列意图。定位和设备 token 的旧队列也按同样原则被取代。
2. **快速连续切换开关：** 一次共享设置保存完成前禁用相关控制；AppStore 同时拒绝第二份过期的整对象提交。相同保护也覆盖逐好友的城市共享／同城提醒开关。保存标识按账号生命周期失效，旧请求不能重置新账号的保存状态。
3. **账号隔离：** 请求固定账号及登录代次，在取 token、刷新 token、返回响应、异常处理和失败入队时重新检查。账号已变化的请求被取消，不能借用新账号提交、刷新或退出其会话。登录交换成功但业务初始化失败时清理未完成会话，避免新 token 配旧账号缓存。
4. **缓存清理：** 退出/确认删除账号后移除对应个人计划、Trips 和旧格式 Trips 缓存；内存中的缓存代次阻止迟到响应重新写回。不会清理其他账号的数据；失效标记只留在内存，不额外保存已删除账号的标记到磁盘。
5. **未来城市匹配：** 新 SQL 触发器与客户端复用当前城市已有的规范化身份，例如 NY / New York。不同州或无法确定行政区的记录不会被猜测为同城。
6. **最后一次提醒重试：** 第五次尝试的有效处理窗口不会被另一任务提前清除；真正过期的窗口仍被回收，权限撤回仍立即使发送失效。
7. **手动城市：** City sharing 增加手动选城，城市包含国家与行政区；“使用设备定位”可恢复自动更新。没有定位权限也能手动选择。
8. **跨年显示：** 个人计划、好友计划和重叠标签在跨年时显示两端年份。
